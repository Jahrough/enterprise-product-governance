# Governance Domains and Architecture

**PROPOSED — pending formal review.** This directory is intended for
cross-cutting architecture and governance domain standards. Future domain
owners and an architecture governance function would maintain applicable
content; none are assigned here.

Candidate domains include application, infrastructure, data, integration,
tenancy, security, privacy, AI, engineering, and operations. Each domain should
identify its scope, dependencies, accountable owner, decision rights,
applicable requirements, risks, controls, and evidence in the
[registers](../09-registers/README.md). Domain decisions inform lifecycle
architecture and assurance, while product-specific tailoring belongs in
[product profiles](../07-product-profiles/README.md).
