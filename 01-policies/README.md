# Policies

**PROPOSED — pending formal review.** This directory is intended for
organizational policy artifacts. An eventual policy governance function and
relevant domain owners would maintain them; no owner has been assigned.

A policy becomes mandatory only when formally approved and applicable.
Nothing in this directory establishes an approved policy. Connect future
policies to standards and controls using the
[artifact and control registers](../09-registers/README.md).
