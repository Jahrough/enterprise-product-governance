# Product Profiles

**PROPOSED — pending formal review.** This directory is intended for
product-specific applicability, tailoring, risks, and dependencies.
Future product owners, supported by domain owners, would maintain profiles;
no owner is assigned. Profiles should link to the governing artifacts,
controls, decisions, and evidence rather than silently override them.

The initial [B2B BI SaaS profile](b2b-bi-saas/README.md) is a set of
assessment topics, not a claim about a deployed product.
