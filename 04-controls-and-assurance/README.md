# Controls and Assurance

**PROPOSED — pending formal review.** This directory is intended for risk,
control, assurance, and evidence practices. A future assurance function and
control owners would maintain the content; no owner is assigned.

For each applicable requirement, identify risks, controls, execution
responsibility, verification method, and evidence. Trace control results and
approvals to the change or release and record gaps and exceptions. Store
evidence in approved systems with appropriate access, retention, integrity,
and privacy protections; do not put sensitive evidence in this repository
without authorization. Review control effectiveness and remediation on an
agreed schedule. The [control register](../09-registers/README.md) defines
the initial schema. A control description or artifact is not evidence that
the control ran or that an audit or certification was achieved.
